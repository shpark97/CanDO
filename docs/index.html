TL;DR. A frozen point cloud model behind a score-only API collapses when inputs arrive in poses it never saw in training. CanDO searches over input rotations with CMA-ES and keeps the one the model is most confident about. It needs only forward queries, with no labels, gradients, weights, or auxiliary models.

Method

Canonicalization by derivative-free search

Rotations have only three degrees of freedom, so the search runs over an axis-angle vector rather than thousands of point coordinates or millions of weights.

Propose rotations

CMA-ES samples a population of axis-angle vectors \(\boldsymbol\theta\in\mathbb{R}^3\), mapped to rotations \(\mathbf R_{\boldsymbol\theta}\) by Rodrigues' formula.

Query the black box

Each rotated copy \(\mathbf P\mathbf R_{\boldsymbol\theta}^{\top}\) costs one forward query and is scored by the model's own confidence. No label or gradient is ever used.

Adapt and select

CMA-ES moves its mean, step size, and covariance toward the best-ranked rotations. After the budget, the most confident pose is kept.

$$J(\boldsymbol\theta)=\frac1N\sum_{i=1}^{N}\max_c\big[g(\mathbf P\mathbf R_{\boldsymbol\theta}^{\top})\big]_{i,c}$$
$$\hat{\boldsymbol\theta}=\operatorname*{arg\,max}_{\boldsymbol\theta\in\{\mathbf 0\}\cup\Theta}\; J(\boldsymbol\theta)-\lambda\lVert\boldsymbol\theta\rVert$$

The confidence surrogate averages per-point maximum probabilities (a single maximum for classification). The identity is always a candidate, and an optional prior \(\lambda\) keeps already-upright inputs untouched.

Analysis

When does confidence-only recovery work?

The paper identifies three conditions, and is candid about where they break.

0.31 → 0.53 S3DIS mIoU under tilt

An augmentation gap

Recovery is possible only for shifts the model was not trained to absorb. A scene model trained with yaw augmentation collapses under tilt, and CanDO restores it; controlled augmentation ablations confirm the causal link.

r = 0.51 confidence vs. accuracy

An aligned surrogate

Dense per-point confidence tracks segmentation quality well. A single classification softmax is a weaker signal, so classification recovers a smaller share of the gap (29 to 42%).

2× global vs. local search

Global search

On the bumpy landscape, local and gradient methods stall at 17 to 27% of the oracle gap, while random search, CMA-ES, and Bayesian optimization reach 53 to 57%.

Code

Use it on your own model

The cando package depends only on PyTorch, NumPy, and pycma. Your model stays a black box.

Install
pip install git+https://github.com/shpark97/CanDO.git
Canonicalize one input
from cando import cando, max_prob_confidence, rotate

def objective(Rs):                                  # (M, 3, 3) candidate rotations
    probs = frozen_model(rotate(points, Rs))        # one forward query per candidate
    return max_prob_confidence(probs)               # (M,) confidence

R, theta, info = cando(objective, budget=300)
prediction = frozen_model(rotate(points, R)[None])
